# CS402: Cryptology Course Projects

This repository contains the projects and assignments for the **CS402: Cryptology** course at the Faculty of Science, Computer Science Department. It includes implementations of various cryptographic algorithms and concepts discussed during the lectures.

-----

## 📜 Description

This project is an educational exploration into the world of cryptology. It serves as a practical implementation of the theoretical concepts learned in the CS402 course. The repository is organized by topic, with each folder containing the source code, and any necessary supporting files for different cryptographic ciphers and protocols.

The primary goal is to build a deeper understanding of how classical and modern cryptographic systems work by implementing them from scratch.

-----

## ✨ Features

This repository includes implementations of the following ciphers and algorithms:

  * **Classical Ciphers:**
      * Caesar Cipher
      * Monoalphabetic Substitution Cipher
      * Playfair Cipher
      * Vigenère Cipher
      * Hill Cipher
  * **Modern Symmetric Ciphers:**
      * Data Encryption Standard (DES)
      * Advanced Encryption Standard (AES)
  * **Asymmetric Ciphers:**
      * RSA Algorithm
  * **Hashing Algorithms:**
      * Implementation of a basic hashing function.

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

You will need to have the following installed on your system:

  * A C++ compiler (like GCC/G++) or Python 3.x, depending on the implementation language.
  * An IDE or code editor of your choice (e.g., VS Code, Code::Blocks, PyCharm).

### Installation & Usage

1.  **Clone the repository** to your local machine:
    ```bash
    git clone https://github.com/M-Sayed939/CS402.git
    ```
2.  **Navigate** to the project directory:
    ```bash
    cd CS402
    ```
3.  Browse to the specific algorithm folder you wish to run. For example, to run the Caesar Cipher:
    ```bash
    cd "Classical Ciphers/Caesar Cipher"
    ```
4.  **Compile and run** the code. For a C++ project, you might use:
    ```bash
    g++ main.cpp -o caesar
    ./caesar
    ```
    For a Python project:
    ```bash
    python main.py
    ```
